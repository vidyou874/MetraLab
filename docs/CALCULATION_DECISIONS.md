# Calculation Decisions Pending Approval

The following choices must be approved by the laboratory technical owner before production use.

| Decision | Required answer |
|---|---|
| OIML R76 edition | Edition/reference used by each supported procedure |
| National/internal procedure | Applicable local adoption and lab procedure revision |
| Error sign convention | Formula such as `E = I - L` |
| Digital rounding correction | Approved method for correcting indication rounding |
| MPE tables | Class, load range, and interval-specific limits |
| Multi-range selection | Deterministic rule for selecting applicable range/interval |
| Units and conversions | Permitted units and exact conversion rules |
| Rounding of reported results | Display precision and comparison precision |
| Uncertainty decision rule | In scope/out of scope; if in scope, guard-band rule |
| Environmental limits | Blocking/warning/not-evaluated behavior outside limits |

Until these are configured and approved, metrological conformity results must return `Not evaluated`.
